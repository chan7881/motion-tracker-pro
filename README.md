# Motion Tracker

동영상 속에서 움직이는 물체를 지정하면 자동으로 추적하여 위치·속도·가속도를
분석해주는 교육용 웹 애플리케이션입니다. 과학 수업에서 실제 촬영한 영상으로
운동을 정량적으로 분석할 때 사용할 수 있도록 만들었습니다.

## 사용 흐름

### 1. 촬영
동영상을 업로드하거나 카메라로 직접 촬영합니다.

### 2. 장면 추출
원하는 프레임레이트(FPS)로 영상을 낱장의 장면으로 추출합니다.

### 3. 크기 보정
화면 속 자나 길이를 아는 물체를 기준으로 실제 길이(m)를 입력해 픽셀 좌표를
실측 단위로 환산합니다.

### 4. 물체 지정
첫 장면에서 움직이는 물체를 네모(ROI)로 지정하면, 나머지 장면에서 그 모습과
가장 비슷한 곳을 템플릿 매칭(ZNCC, 정규화 상호상관)으로 찾아 자동 추적합니다.
추적이 흔들린 장면은 신뢰도 색상으로 표시되며, 해당 장면에서 위치를 다시
지정해 그 장면부터 뒤쪽만 재추적할 수 있습니다.

### 5. 결과
위치·속도·가속도 그래프, 이동 경로 시각화, CSV 및 추적 경로가 표시된 영상
다운로드를 제공합니다.

- 좌표: 화면 왼쪽 아래 모서리가 원점, 오른쪽이 +x, **위쪽이 +y** (떨어지는
  물체의 vy·ay는 음수).
- 속도·가속도: 이웃한 5개 장면에 2차식을 최소제곱으로 맞춰 구합니다. 가속도가
  일정한 운동이면 처음·끝 장면과 추적에 실패해 건너뛴 장면이 있어도 정확합니다.
  추적 실패(신뢰도 0) 장면은 계산에서 뺍니다.
- 가속도는 추적 잡음에 훨씬 민감해서, 장면이 촘촘하면 약 0.2초에 걸친 장면들로 맞춥니다
  (10 fps 이하 5개, 30 fps 7개, 60 fps 13개).

## 기술 스택

Vite / React / TypeScript / shadcn-ui / Tailwind CSS / recharts(그래프)

## 테스트

```sh
npm test   # 속도·가속도 계산을 등가속도·단진동 이론값과 대조 (Node 22 이상)
```

## 로컬 개발

```sh
git clone <이 저장소 URL>
cd motion-tracker-pro
npm i
npm run dev
```

## 배포

`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가
자동으로 빌드하여 GitHub Pages에 배포합니다.
